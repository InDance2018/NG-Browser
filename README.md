# NG-Browser

**Der öffentliche NeverGate-Browser für Windows.**

Dieses Repository dokumentiert ausschließlich NG-Browser: Produktstand, Einstieg, Änderungsverlauf und offene Nachweise. Es enthält derzeit **keinen veröffentlichten Quellcode und keinen Installer**.

## Download für Windows

**[NG-Browser im Microsoft Store herunterladen](https://apps.microsoft.com/detail/9NQZ4GP7K4TX)**

## Stand · 01.11.2026

- Die Veröffentlichung im **Microsoft Store** wurde vom Projektinhaber bestätigt.
- Die zuvor besprochenen Sandbox-/Netzwerkprobleme sind laut aktueller Eigentümerrückmeldung **behoben**.
- Die genaue aktuell ausgelieferte Store-Version und ihre Zuordnung zu einem Build wurden in dieser Dokumentationsaktualisierung nicht unabhängig überprüft.

Eine behobene Störung wird hier nicht erneut als aktueller Fehler geführt. Zugleich ist eine einzelne Rückmeldung kein Nachweis sämtlicher Browserfunktionen auf allen Windows-Systemen.
