# Einstieg und Fehlerberichte · NG-Browser

## Installation und Updates

Die Microsoft-Store-Veröffentlichung ist vom Projektinhaber bestätigt. Verwende den offiziellen Produkteintrag für NG-Browser; dieses Repository liefert keinen separaten Installer. Ein verifizierter direkter Store-Link wird ergänzt, sobald der konkrete Eintrag für die Dokumentation abgeglichen ist.

Notiere bei Fragen die angezeigte Produktbezeichnung, Browser-Version und Windows-Version. Ein Dokumentationsupdate auf GitHub installiert kein Browserupdate.

## Nach einem Update prüfen

1. Browser normal öffnen und eine bekannte Webseite aufrufen.
2. Die regelmäßig verwendeten Seiten und Anmeldungen prüfen.
3. Bei einer Störung feststellen, ob nur eine Seite oder mehrere Seiten betroffen sind.
4. Fehlermeldung und Schritte notieren. Keine Konten, gespeicherten Zugänge oder Profile vorschnell löschen.

Die frühere Sandbox-/Netzwerkstörung ist als behoben gemeldet. Dieses Handbuch empfiehlt **nicht**, Schutzfunktionen abzuschalten oder systemweite Netzwerkänderungen auf Verdacht auszuführen.

## Einen Fehler melden

Ein hilfreicher Bericht enthält:

- Produktname **NG-Browser**, sichtbare Versionsnummer und Windows-Version;
- kurze Schritte zum Nachstellen;
- erwartetes und tatsächliches Ergebnis;
- gegebenenfalls den genauen Fehlertext;
- ob es nach erneutem Öffnen weiter auftritt und welche Art von Seite betroffen ist.

Keine Passwörter, Cookies, Tokens, privaten Webseiteninhalte, vollständigen Profile oder Zugangsschlüssel öffentlich hochladen. Bilder auf persönliche Daten prüfen.

## Weitere Anleitung

Eine vollständige bebilderte Beschreibung der konkreten Menüs folgt auf Basis einer eindeutig zugeordneten öffentlichen Version. Geplante Funktionen werden nicht als bereits vorhandene Bedienmöglichkeiten erklärt.
